Testing Strategy At A Glance

1

Compile Gate

Proves Python files in app and tests compile before behavior checks run.

2

Static Import Gate

Checks module imports and guards against low-level LLM calls bypassing the gateway.

3

Unit Guards

Exercises SQLGuard, Hl7Guard, TokenGuard, RAG, calculator specs, grants, and memory rules.

4

Endpoint Flows

Validates query, ORU parse, parse-session save, replay denial, wrong-session denial, and redaction.

5

Abuse Tests

Locks down prompt injection, SQL-like HL7 notes, stale history authority, guessed tokens, and bad grants.

6

Future Gates

Add production read grants, UI escaping, durable taint metadata, and deeper admin/read authorization tests.

What Is Covered Well

Strong

Core Query Kernel

  • Classifier failure fails closed.
  • Deny intents do not call the agent.
  • Client history cannot create authority.
  • References resolve from safe state only.
  • Timeouts do not commit memory.
Strong

Database And Tool Governance

  • Warden blocks unregistered tools and bad schemas.
  • Grant subject limits patient context.
  • SQLGuard blocks mutation/control SQL.
  • Raw HL7/FHIR SQL columns are denied.
  • Note text columns require note_read.
Strong

HL7 And Persistence

  • Invalid HL7 is denied safely.
  • SQL-like note content is denied.
  • Parse preview creates server-owned parse_id.
  • Wrong-session and replayed parse IDs fail.
  • Client-tampered clinical JSON is ignored.

Coverage Gaps

Gap Why It Matters Recommended Test Slice
Read-output grants Patient/message list endpoints still return demo identifiers without per-request output grants. Add endpoint tests for patient list, timeline, summary, message list, and protected fields.
Durable taint metadata Note redaction currently uses naming heuristics like NOTE or display text. Add ingestion-time note/text classification and verify every read path consumes it.
MLLP ingestion app/mllp_server.py can call the ORU pipeline outside the API kernel path. Current tests prove HL7Guard and audit before pipeline. Future tests should add parse-session parity if MLLP stays enabled.
Admin and document audit Basic PHI-free audit is now covered for reset and document access. Add actor-aware authorization once users/RBAC exist.
UI escaping Server guards are strong, but browser rendering can still become an output boundary. Use browser tests for escaped HL7, FHIR, RAG snippets, markdown, traces, and notes.
True cancellation Python threads cannot forcibly kill already-running LLM/tool work after timeout. Add cooperative cancellation or process/job isolation tests for long-running LLM/RAG/SQL paths.
Result references conversation_result_refs exists but is not a complete lifecycle yet. Add save/load/expire/wrong-session tests, then wire reference resolution to live result refs.

Bottom-Line Report

Compile coverage is good. Core governance execution coverage is strong. Endpoint coverage is strong for query, HL7 parse, and parse-session persistence. Coverage is improved for read audit, admin audit, document audit, and MLLP guard entry. The next testing priority should be expanding output-grant and audit coverage to every PHI-bearing read path, then validating durable note taint metadata and UI escaping.
