Security Kernel State Diagram

A browser-friendly state map for Warden 2.0: boundaries, wristband metadata, state transitions, enforcement gates, audit, and tests. The key rule is simple: every operation gets fresh server-created authority, while memory and handles remain references only.

Hospital Metaphor

Metadata is the wristband. State is where the patient or item is in the hospital process. Gates are the staff checks. Audit is the receipt book. Tests are the fake-wristband drills.

Core security law User text, browser JSON, RAG chunks, HL7 notes, and LLM output may provide evidence. They cannot print official wristbands. Only server-created metadata can authorize tools, persistence, memory commits, or PHI restoration.

Query State Machine

The query path is a single-request authority flow. Safe memory can help resolve references, but it does not carry permission forward.

Boundary

User Question

/api/query receives tainted text, history, and depth.

Metadata

Canonical Input

Normalize, mark taint, load session and request identifiers.

State

Safe Memory

Resolve "his" or "first one" from typed state only.

Authority

Intent Grant

Server creates fresh allowed tools, subject, scope, fields, and TTL.

Gate

Warden + Guards

Validate tool schemas, grant scope, SQL, RAG, calculator, and tokens.

Commit

Answer + Memory

Output gate restores allowed tokens; memory commits only on success.

Invariant: no failed, denied, timed-out, interrupted, stale, or clarification-pending query may commit conversation memory.

HL7 Parse And Save State Machine

HL7 is a two-step workflow. The browser receives a temporary claim ticket called parse_id, but the server owns the actual parse result.

Boundary

Raw HL7

/oru/parse receives untrusted message text.

Gate

HL7Guard

Check MSH, PID, ORU shape, field caps, nulls, note policy.

State

Validated Parse

Server builds patient, observations, FHIR, alerts, and note metadata.

Ticket

Parse Session

Store parse_id, session, raw hash, status, result, expiry.

Persist

Claim And Save

/messages atomically claims same-session parse once.

Parse Session Status

validated -> persisting -> persisted or expired
Invariant: client-supplied FHIR, observations, patient fields, trust, status, or summary cannot become clinical truth. The persisted record must come from the server-owned parse session.

Token Restore State Machine

PHI token maps are request-local RAM state. They are intentionally not durable. Losing them after a restart is safer than persisting token-real pairs.

RAM

Token Map Created

Warden builds fresh request-scoped mappings from DB values.

Record

TokenRecord

Token gets request, field type, source, output authorization.

Gate

Output Check

Restore only if request, live grant, field type, and authorization match.

Fail Closed

Redact

Guessed, stale, wrong-request, or injected tokens become redacted text.

Cleanup

Clear RAM

Request exit clears the map. Audit stores counts only.

Where State Lives

Store What Lives There Why Security Rule
RAM Warden request scope, token-real maps, temporary prompt/tool data. Minimize PHI at rest and clear secrets after each request. Never persist token-real pairs. Restart fails closed.
SQLite Demo sessions, parse sessions, safe conversation state, result refs, audit events. Persist workflow state and audit receipts across requests. State must have owner, status, expiry, and safe payloads.
Browser Cookie session handle, parse_id, normal response body. Let the UI continue a workflow without owning authority. Handles are references only. Server verifies every use.

Invariant Matrix

Invariant Primary Gate State Checked Failure Behavior
No tool runs without a server-owned grant. Warden IntentGrant allowed_tools, expiry, scope, subject. Deny before tool execution.
No SQL executes without deterministic validation. SQLGuard Grant tables, columns, max rows, note policy. Reject SQL draft and return safe error.
No parse_id can persist twice. Parse session claim Same session, status validated, unexpired. Invalid or expired parse session.
No stale or guessed token restores PHI. TokenGuard/Warden output gate Request id, live grant, field type, output authorization. Redact token.
No failed request commits memory. Safe memory commit gate Success, no error, no clarification, current session. Skip memory commit.
No raw PHI appears in canonical audit. Audit sanitizer Blocked keys and safe payload rules. Redact payload fields before insert.

What To Test

Backtracking Replay parse_id, use old tokens, expired memory, and old fallback paths.
Metadata Injection Fake grants, fake trust_level, fake admin JSON, fake prior assistant claims.
Boundary Abuse Prompt injection, SQL injection, RAG poison, HL7 note control text.
Side Effects Denied and timed-out flows must not persist, commit memory, or leak PHI.
Audit Safety Audit must contain reason codes and counts, not raw patient content.
Happy Paths Valid query, valid parse preview, and same-session parse save still work.
