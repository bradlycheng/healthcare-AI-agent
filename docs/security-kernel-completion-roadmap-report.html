What Was Completed

Reference And Memory

  • Added safe reference resolver.
  • Pronouns and ordinals resolve only from safe state.
  • Ambiguous references clarify instead of guessing.
  • Export and identifier jumps deny.
  • Failed, denied, timeout, and clarification turns skip memory commit.

Query Governance

  • Client history no longer acts as authority.
  • Resolved subjects stay structured in grants.
  • Warden denies patient context outside grant subject.
  • SQL generation ignores raw history.
  • sql_used hidden unless debug-enabled.

Output Protection

  • Raw HL7 detail redacted by default.
  • FHIR detail redacted by default.
  • Note-like observation values redacted by default.
  • SQLGuard blocks note text columns unless note_read.
  • Token restore summaries are aggregate-only.

Cleanup And Timeout

  • Central conversation TTL used by safe memory.
  • Expired transient security state cleanup added.
  • Request timeout returns safe no-commit result.
  • Timeout executor is bounded.
  • Startup cleanup never resumes clinical work.

Multi-Agent Reports

  • Explorer A mapped memory/reference paths.
  • Explorer B mapped endpoint/output policy.
  • Reviewer identified bypass risks.
  • Lead integration summary records decisions.
  • Reports live under docs/agent-reports/next-hardening.

Future Roadmap

Slice 1

Read Output Grants

  • Add read grants for patient/message/timeline endpoints.
  • Decide demo identifier policy versus protected mode.
  • Audit admin/reset/document reads.
Slice 2

Durable Taint Metadata

  • Add row-level note/text classification.
  • Backfill legacy text rows.
  • Use one taint source across SQL, API, timeline, synthesis.
Slice 3

Result References

  • Implement result-ref save/load helpers.
  • Add TTL and same-session ownership.
  • Resolve result references without exposing raw rows pre-grant.
Slice 4

Production Boundary

  • Wrap MLLP server in HL7 kernel.
  • Add RBAC/OAuth or production auth.
  • Replace debug flags with actor/grant authorization.

Bottom Line

The core kernel is now strong enough for the next demo-security checkpoint: LLM output does not create authority, client clinical JSON does not create truth, failed/denied/timeout requests do not commit memory, and the highest risk query/HL7/message paths have tests. The remaining work is mostly about expanding the same kernel guarantees to read endpoints, production auth, durable taint metadata, MLLP ingestion, and UI validation.
