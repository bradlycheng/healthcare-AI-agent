Operational Defaults

Decided defaults that support the V2 target architecture without adding full production auth or platform operations.

Admin/user auth
Full users/RBAC/OAuth are deferred. Reset/admin stays password-protected and cannot be delegated to chat or LLM.
Protected traces
ai_interactions stays for governance/debugging, but it is PHI-bearing trace data, not PHI-free audit or live authority.
Legacy stored notes
Old notes/messages may predate ingress policy, so retrieval treats them as tainted clinical text.
HL7 idempotency
parse_id, raw HL7 hash, and/or request_id prevent accidental duplicate saves on retry.
Safe errors
User errors are generic. Internal reason codes are detailed but audit-safe; no raw HL7, PHI, token maps, stack traces, or rule details.
Audit source
governance_events is the canonical PHI-free audit record. Warden JSONL can remain as temporary compatibility/debug output only.
CORS/CSRF
Production hardening is deferred, but kernel code must not assume permissive demo CORS or unauthenticated sessions are production-safe.
/messages compatibility
Client-supplied clinical JSON is never authoritative. Strict reject by default; transition mode may accept only while recomputing/ignoring fields.
Timeouts
Timeouts are configurable per stage. Timeout cleanup marks incomplete work interrupted/expired; it does not resume or complete clinical work.
Trace retention
Trace retention is configurable and short by default for PHI-bearing ai_interactions in demo/prototype deployments.

Practical Guardrails

Realistic controls for known weak spots without expanding V2 into full production auth, full migrations, or a large security platform.

PHI-safe audit helper
emit_governance_event accepts codes/counts/categories and rejects or redacts raw text, raw HL7, token maps, PHI names, DOB, and FHIR payloads.
Namespaced config
SECURITY_CONFIG groups timeouts, ttl, retention, compatibility, and deployment settings.
Simple migrations
schema_migrations marker plus idempotent CREATE TABLE/INDEX keeps SQLite setup verifiable.
Safe output proof
At least one test proves script-like content in HL7/FHIR/RAG/notes is escaped or safely rendered.
Invariant tests
Assert no ungated fallback, no direct LLM imports, no client-trusted messages clinical truth, and no missing-grant tool execution.
LLM gateway shape
Gateway dispatches task-specific schemas/prompts instead of becoming one giant mixed prompt module.
Simple RAG trust
Use DEMO_SEEDED_DOC, TRUSTED_LOCAL_DOC, USER_UPLOADED_UNTRUSTED, or UNKNOWN plus source_hash and warnings. UNKNOWN is restricted or denied in high-risk flows.
Legacy note taint
Notes without new policy metadata become legacy_unverified_note at retrieval.
Transition mode off
/messages legacy transition is disabled by default; if enabled, old clinical fields are logged as ignored and recomputed.
Secrets basics
Admin reset password comes from env/config; missing password disables or blocks reset; secrets are never logged.

Fail Closed Everywhere

Any missing grant, invalid schema, unsafe SQL, bad HL7, stale parse_id, unauthorized token, or guard error denies, redacts, or asks for clarification. No silent downgrade to a weaker path.
Agent failure cannot fall back to ungated legacy query.
Client FHIR and observations cannot become clinical truth.
RAG chunks and stored notes cannot grant tools, SQL, memory, or policy.
Untrusted metadata-looking fields cannot create authority.
Token restore requires request ownership and field authorization.
