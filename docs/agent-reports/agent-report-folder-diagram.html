Agent Report Folder Diagram

Agents run inside Codex. They do not sit in the repository as files. The repository stores their reports, summaries, handoff notes, and verification results.

Yellow = folders
White = report files
Blue = agent work
Green = lead Codex
Purple = verification

Read This First

Agents run in Codex Explorer, worker, and reviewer agents are temporary helpers. They are not folders and they are not stored in Git.
Reports are files Each agent writes findings or handoff notes into a Markdown report under the report folder.
Lead Codex decides The lead reads reports, combines them into a summary, then decides what becomes implementation work.
docs/agent-reports/ = report storage, not where agents live

Where Verification Sits

Verification is not a separate folder-first step. It happens after an agent report, after the lead summary, after each implementation phase, and during reviewer security pass.
verification timeline
Agent report Focused findings or worker handoff.
Lead review Checks fit against the kernel architecture.
Phase summary Combines reports into one decision point.
Validation gate Runs required tests and invariant checks.
Reviewer pass Searches for bypasses, PHI leaks, stale authority, and missing tests.

Important Rule

Agents are not stored in the repo. Only reports are stored. Lead Codex decides what reports become implementation.
